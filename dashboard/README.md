# Dashboard layer

**Tableau: presentation layer prepared; native dashboard not built.** Presentation-ready dashboard tables and specifications were prepared, but no native Tableau workbook or dashboard was ultimately built. The project was frozen in October 2026 with four static Python figures as its visual layer: see [figures/](../figures/), generated by `python -m src.visuals.make_figures` (requires matplotlib).

The six tables in [data/processed/](../data/processed/) were shaped for Tableau and can still be used to build a workbook. Anyone doing so should keep product and offer counts separate, treat unknown features as unknown, compare Google Trends values only within one request, and use the corrected critical-severity counts (141 rows).
