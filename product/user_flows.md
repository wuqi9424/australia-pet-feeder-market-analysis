# User Flows

The frozen set has 31 flows: 12 normal flows F01–F12 and 19 exceptions E01–E19. Local setup checks time, configures, reviews, persists and inspects the active plan. Scheduled execution produces attempt evidence, not automatic success. Status review inspects evidence and freshness first.

Remote editing separates Draft, Change sent, Waiting for device confirmation, Device confirmed and Could not confirm. A matching request/version acknowledgement proves configuration, not food output. Offline views show last sync and cached labels, disable remote controls and condition local continuation on valid power/time/configuration. Reconnection proves no meal outcome. Maintenance pauses, cleans/refills, reassembles, checks and explicitly resumes. Near-meal manual feeding and missed-meal catch-up remain unresolved, without invented retry policies.

Eight App screens plus one simplified local concept use grayscale low fidelity and optional App access. A runs Home→Schedule→Edit→Review→Send→Pending→matching device acknowledgement. B shows offline/cached/last-sync information, conditional local continuation and reconnect. C moves from an attempt to Delivery unconfirmed, known/unknown explanation and safe checking, without automatic retry.

SVG and HTML assets copy frozen Phase 9D rather than redesign it. Fixture controls drive demonstration conditions, not hardware capabilities. No native Figma, industrial interface or usability test exists. Selected screens are available in shared assets.
